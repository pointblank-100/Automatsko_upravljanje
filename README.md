Projekat iz predmeta Automatsko upravljanje.
U zipu projektni_zadatak nalazi se folder sa .ap16 fajlom gorepomenutog projektnog rada.
Ovaj fajl je bio testiran samo u verziji TIA Portal-a v16, upgrade-ovanje fajla u novije verzije TIA Portal-a je tehnicki moguce ali ce verovatno dovesti do nekih komplikacija prilikom pokretanja fajla.
Uz zip se nalazi i MATLAB skripta za ocitavanje logging fajla koji je u TIA Portal-u definisan kao .txt fajl koji se cuva po default-u na lokaciji C diska u folderu Storage Card SD, pa zatim u folderu logs/Logging_file.
